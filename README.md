# Clube G7 v2

Tenho um aplicativo chamado Clube G7. Quero fazer uma nova versão. Vou enviar as tela de como ele funciona hoje. Faça uma nova proposta. 

Esta app, é acessado nos celulares, então priorize o first-mobile. 

O cliente ganha cashback ao abastecer ou fazer compras no postos de combustíveis do Grupo7. Ao acessar o app Clube G7 ele consulta o seu saldo de cashback, e também o histórico dos últimos atendimentos, o qual pode ser avaliado a qualidade do atendimento.
